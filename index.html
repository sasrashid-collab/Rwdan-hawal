🚀 بڵاوکردنەوەی ماڵپەڕ

١ ماڵپەڕەکەت دابەزێنە یان بینێرە بۆ GitHub

یەکێک هەڵبژێرە:

٢ لە Netlify هاوستی بکە

  1. بچۆ بۆ app.netlify.com/drop
  2. فۆڵدەرەکەی تێدا index.html هەیە ڕاکێشە
  3. لە ١٠ چرکەدا لینکێکت دەداتێ — هەموو کەسێک دەتوانێت بیکاتەوە

٣ سیستەمی خۆکارانە (GitHub Actions + Telegram)

بۆ ئەوەی هەواڵەکان خۆکارانە کۆبکرێنەوە و بڵاو بکرێنەوە:

  1. لە GitHub ئەکاونتێک دروست بکە
  2. Repository ی نوێ دروست بکە: rudanai
  3. فایلی index.html و .github/workflows/news-bot.yml زیاد بکە
  4. لە Telegram بۆتێک دروست بکە و Token وەربگرە
  5. کەناڵی تێلەگرام دروست بکە: @rudanai_news
  6. لە GitHub Settings → Secrets → Actions:
    • TELEGRAM_BOT_TOKEN = tokenەکەت
    • TELEGRAM_CHANNEL_ID = @rudanai_news
  7. هەر ٣٠ خولەک جارێک، هەواڵەکان خۆکارانە بڵاو دەبنەوە!
💡 هەموو ئەمانە بەخۆڕایی و بەبێ کارتی بانکن.
